# Fonts

Served for the Archives page text, in a collegiate style.

- `graduate-latin.woff2`: Graduate by Eduardo Tunni, Latin subset (headings, labels, buttons).
- `libre-caslon-text-latin.woff2` and `libre-caslon-text-italic-latin.woff2`:
  Libre Caslon Text by Impallari Type, Latin subset (body text).

All are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org)
and were taken from Google Fonts. Hebrew, Farsi and Arabic text falls back to
Georgia and the system fonts.
