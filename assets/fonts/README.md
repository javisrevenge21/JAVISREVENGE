# Fonts

Served for the Archives page text.

- `cinzel-latin.woff2`: Cinzel by Natanael Gama, Latin subset.
- `cormorant-garamond-latin.woff2`: Cormorant Garamond by Christian Thalmann, Latin subset.

Both are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org)
and were taken from Google Fonts. Hebrew, Farsi and Arabic text falls back to
Georgia and the system fonts.
